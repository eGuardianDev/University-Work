## Как работи уеб приложението (2 час)

Схема на потока:

```text
User → Browser → Server (IIS / Apache / nginx) → PHP (PHP / JS) ⇄ Database
```

- **User** – потребител
- **Browser** – браузър
- **Server** – уеб сървър: IIS, Apache, nginx
- **PHP** – обработва заявката (отбелязано „PHP“, „JS“ над кутията)
- **Database** – база данни; връзката с PHP е двупосочна (⇄)
