## Начало и край на PHP код

```php

```

или

```php

```

Слагаме точка и запетая `;`

```php
echo "Hello";
```

## Коментари

```php
// коментар

/* многоредов */
```

- Многоредов коментар: „все по default“ → преди `/*` затваря първото отворено. Тоест ако имаме няколко едни след други отворени коментари, ще се затворят всичките

```html
<!-- ... -->
```
- → HTML коментар (HTML comment) – може да се види в „inspect“.
  - ↳ Дори да закоментираме js, php, etc., то пак се изпълнява (execute-ва) преди да се изпрати.

## Променливи и конкатенация

```php
$something   // променлива (variable)

echo $text1 . " " . $text2;   // конкатенация (concat)
```

- names – чувствителни към главни/малки букви *(?)*
- `getType()`

```php
$data = $_GET["user"] ?? "else";
```

- → URL: `?user=...`
