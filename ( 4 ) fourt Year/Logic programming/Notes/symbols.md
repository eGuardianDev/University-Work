# Logic

| Symbol | Name | Primary Meaning | Common Use Case | Example |
| :--- | :--- | :--- | :--- | :--- |
| $\triangleq$ | Triangle Equal | **Equal by definition** | Introducing a brand-new variable, function, or shorthand notation. | $f(x) \triangleq x^2 + 2$ *(Defining the function f)* |
| $\doteq$ | Dot Equal | **Approaches equality** or **is virtually equal** | Showing that two distinct things evaluate to the same limit, are structurally equivalent, or match closely. | $e \doteq 2.718$ *(Approximating the value of Euler's number)* |
| $\equiv$ | Identically Equal / Equivalent | **Identical for all variables** or **Modular congruence** | Stating identities that are true no matter what, or indicating modular math. | $\sin^2(x) + \cos^2(x) \equiv 1$ <br> $12 \equiv 2 \pmod{10}$ |
| $:=$ | Colon Equal / Assignment | **Assigned definition** | Setting a programmatic value or mapping a definition from right to left. | \(x := 5\) *(Setting the value of x to 5)* |








# Other

| Symbol | Name | Primary Meaning | Common Use Case | Example |
| :--- | :--- | :--- | :--- | :--- |
| $\lessgtr$ | Less-than Greater-than | **Less than OR greater than** (Stacked) | Presenting stacked multi-case conditions or a dynamic choice between upper and lower branches. | $H_0 \lessgtr H_1$ *(Commonly used in statistical hypothesis decision boundaries)* |
| $\gtrless$ | Greater-than Less-than | **Greater than OR less than** (Stacked) | Used similarly to $\lessgtr$, depending on which branch scenario takes precedence. | $A \gtrless B$ |
